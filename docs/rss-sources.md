## Рекомендуемый порядок подключения

1. Сначала проверить HSE announcements и HSE Moscow RSS через текущий RSS-парсер и убедиться, что D1 получает записи без ошибок.
2. Отдельно проверить mos.ru RSS. Из-за широкой тематики не публиковать его записи без строгой фильтрации.
3. Для «Молодёжи Москвы» и других официальных сайтов сначала изучить доступные публичные способы получения данных и условия использования. Не обходить авторизацию, CAPTCHA или технические ограничения.
4. Добавлять источники по одному, после каждого — проверять /collect, /queue и отсутствие повторов.
5. hh.ru, Работа.ру и Авито использовать для ручного отбора, пока не подтверждены разрешённые способы автоматизированного использования их данных.

## Минимальные правила качества для будущей автоматической публикации

- Сохранять первоисточник и прямую ссылку на исходную публикацию.
- Не копировать полные тексты объявлений; публиковать короткое описание и ссылку.
- Проверять дату публикации и дедлайн/дату события, если они указаны.
- Проверять связь с Москвой: место проведения, московский работодатель/организатор либо явно доступный удалённый формат.
- Не считать сам факт наличия записи в RSS подтверждением достоверности или актуальности.
- Сомнительные, рекламные, финансовые и юридически чувствительные предложения отправлять на ручную проверку.
- Автоматическую публикацию включать только после накопления статистики качества по каждому источнику.
