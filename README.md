# Москва: возможности — Telegram-бот (MVP)

Бот собирает RSS-материалы, сохраняет их в SQLite, помогает администратору просматривать и одобрять публикации, а затем публикует их в канал.

## Что умеет
- Регулярно проверять RSS-источники (по умолчанию раз в 60 минут).
- Не добавлять дубликаты ссылок.
- Категоризировать материалы по ключевым словам.
- Хранить очередь в SQLite.
- Одобрять/отклонять материалы командами.
- Публиковать одобренные материалы в канал.
- Показывать базовую статистику.
- Сохранять рекламные черновики.

## Чего пока НЕ делает
- Не накручивает подписчиков и не рассылает приглашения.
- Не гарантирует рост канала или доход.
- Не проверяет фактическую достоверность вакансии автоматически.
- Не запускается сам по себе: нужен постоянно работающий компьютер или хостинг.
- Не принимает платежи и не продаёт рекламу автоматически.

## Запуск
1. Установите Python 3.11+.
2. Создайте бота через официальный `@BotFather` и скопируйте токен.
3. Создайте публичный Telegram-канал.
4. Добавьте бота администратором канала с правом публикации сообщений.
5. Узнайте свой Telegram numeric user ID и укажите его в `ADMIN_IDS`.
6. Скопируйте `.env.example` в `.env` и заполните значения.
7. Установите зависимости:
   `python -m venv .venv`
   `source .venv/bin/activate`
   `pip install -r requirements.txt`
8. Запустите:
   `python app/bot.py`

## Команды
- `/help`
- `/collect`
- `/queue`
- `/approve ID`
- `/reject ID`
- `/publish ID`
- `/feeds`
- `/addfeed Название | https://example.com/feed.xml`
- `/stats`
- `/ad Текст рекламного предложения`

## Безопасность
- Никогда не публикуйте токен бота в чате или репозитории.
- Не выдавайте боту права администратора, кроме необходимых для публикации.
- Используйте только RSS-источники, условия которых разрешают такое использование; сохраняйте ссылки и атрибуцию.
- Для вакансий, мероприятий и рекламы проверяйте дату, первоисточник, условия и законность публикации.
- Рекламные публикации должны быть корректно маркированы в соответствии с применимыми требованиями.
